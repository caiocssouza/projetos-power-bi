# 📊 Balanço Patrimonial

Dashboard desenvolvido com o visual de Matriz no Power BI para análise do Balanço Patrimonial entre 2019 e 2023.

## 📈 Resultados

| Métrica | Valor |
|---|---|
| Total Ativos | R$ 6.462.502,39 |
| Total Passivos | R$ 6.462.502,39 |
| Período | 2019 – 2023 |

## 🛠️ O que foi aplicado

- **Visual de Matriz** com hierarquia Ativo / Passivo / Patrimônio
- **Drill-down** por subcategorias (Circulante, Não Circulante, Capital Próprio, Lucros Acumulados)
- **Segmentação por ano** para filtrar o período analisado
