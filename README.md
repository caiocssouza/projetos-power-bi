## 🛠️ Habilidades desenvolvidas

**Power Query (ETL)**
- Tratamento de nulos, duplicatas e inconsistências de tipo
- Unpivot de colunas (wide to long) com `Table.UnpivotOtherColumns`
- Conversão de datas em formato americano MM/DD/AAAA
- Criação de colunas de auditoria e flag

**DAX**
- `CALCULATE` com filtros contextuais
- `DIVIDE` para divisões seguras
- `AVERAGEX` para médias dinâmicas
- Time Intelligence: variação MoM (Mês a Mês)


**Visualização**
- Gráficos de linha, barra e matriz interativa
- Segmentações dinâmicas por período e categoria
- Linha de média em gráficos de barras
- Cartões com valores completos sem abreviação
