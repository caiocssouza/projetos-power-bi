
# 📦 04 - Análise de Logística

Dashboard desenvolvido no curso **Microsoft Power BI Para Business Intelligence e Data Science** da Data Science Academy, analisando dados reais de entregas.

## 🗂️ Fonte de Dados
Base com **53.770 entregas** contendo informações de status, datas, regiões e vendedores — período 2019 e 2020.

## 🛠️ Ferramentas Utilizadas
- Microsoft Power BI
- Power Query (ETL)
- DAX (Data Analysis Expressions)

## 🧠 O que aprendi
- Diferença entre FILTER e o filtro direto do CALCULATE
- Uso de operadores lógicos `||` e `&&` no DAX
- Criação de medidas rápidas com classificação por estrelas ⭐
- Controle de granularidade dos dados pela aba de filtros

## 📊 Principais Insights
- 87% de SLA — 46.793 entregas dentro do prazo de 53.770
- 70,7% das entregas foram antecipadas
- Apenas 13% de entregas atrasadas
- Região Norte liderou com 27,44% das entregas
