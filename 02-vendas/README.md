📊 Projeto 2 — Análise Comercial
Projeto desenvolvido durante o curso Microsoft Power BI Para Business Intelligence e Data Science da Data Science Academy.
🛠️ Ferramentas Utilizadas

Microsoft Power BI
DAX (Data Analysis Expressions)
AppSource (visuais personalizados)

📁 Fonte de Dados
Base comercial com dados de vendas por produto, categoria, fabricante, segmento, loja, cidade, estado e vendedor.
📊 Dashboards (4 páginas)
Narrativa Inteligente
Geração automática de texto com os principais números e variações do dataset.
Principais Influenciadores de Venda
Visual com machine learning automático para identificar quais variáveis mais impactam o ValorVenda.
Faixas de Categoria x Venda por Loja
Gráfico Sankey mostrando o fluxo de vendas entre categorias e lojas.
Performance Vendedor x Estado
Mapa geográfico com distribuição de vendas por vendedor e localização.
